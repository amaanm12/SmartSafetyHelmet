Connection settings

Enter the ESP32's local Wi-Fi IP address. The dashboard polls http://<IP>/api/data every 2 seconds. Leave it blank to use the live demo simulation.

GitHub Pages uses HTTPS

This page searches for http://shieldguard.local/api/data using mDNS as soon as it opens. A browser cannot receive the ESP32's UDP broadcast directly; the beacon is available to local network tools, while this page uses mDNS and HTTP. In Chrome or Edge, allow the browser's local network access prompt for this site. If HTTP is still blocked, open the site controls beside the address bar, choose Site settings, set Insecure content to Allow, then reload. The ESP32 also sends CORS headers. Browser labels vary, and some browser/network combinations still block this connection.

Expected JSON shape

{ "workers": [{ "id": "1", "temperatureC": null,
  "sensorTemperatureC": 25.4,
  "acceleration": { "x": 0.1, "y": 0.0, "z": 9.8 },
  "gyroscope": { "x": 0.0, "y": 0.1, "z": 0.0 }, "sos": false }] }

Also accepts a single worker object, common flat accX/gyroX fields, or arrays [x, y, z].
